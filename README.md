# Ediciones de video — Sensation Academy

Motor de edición en Remotion con la identidad visual de Sensation Academy. El flujo completo está en `CLAUDE.md`.

- `originales/`: videos originales (no se modifican).
- `salida/`: videos finales en MP4.
- `src/brand/`: intro, cierre, marca de agua, rótulos, tarjetas, separadores, subtítulos, transición e iconos.
- `src/engine/`: el motor que compone cada edición (`Edit`).
- `src/videos/`: la edición de cada video.
- `scripts/`: preparación de audio y análisis, transcripción, render y control de calidad.

```bash
npm i
npx remotion studio
```
